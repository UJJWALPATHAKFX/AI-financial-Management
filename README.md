# FinCoach AI 💹

A futuristic personal AI financial management coach built for college students in India. Powered by **Google Gemini 2.0 Flash**.

![FinCoach AI](https://img.shields.io/badge/AI-Gemini%202.0%20Flash-blue?style=flat-square)
![HTML](https://img.shields.io/badge/Built%20with-HTML%2FCSS%2FJS-orange?style=flat-square)
![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

## Features

- **Dashboard** — Live spending metrics, category breakdown, recent transactions
- **Expense Logger** — Log expenses with category tagging
- **AI Coach** — Gemini-powered personalized financial advice using your real spending data
- **Budget Config** — Set and manage monthly budget limits
- **Futuristic Design** — Dark cyberpunk UI with animated grid, scan lines, and glowing accents

## Tech Stack

- Pure HTML, CSS, JavaScript (zero dependencies, zero build step)
- Google Gemini 2.0 Flash API for AI chat
- Deployed via GitHub Pages

## Setup & Run

### Local

Just open `index.html` in any browser. No server needed.

### Live (GitHub Pages)

See deployment steps in the project documentation.

## API Key

Get your free Gemini API key at [aistudio.google.com](https://aistudio.google.com) → **Get API Key**.
Paste it into the AI Coach tab inside the app.
